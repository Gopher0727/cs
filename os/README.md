## 处理器调度（进程、线程、调度、同步、死锁）

**多级反馈队列**：设置多个就绪队列，优先级从高到低，时间片从小到大。新进程先进入第一个队列，如果时间片用完还没有结束任务，就降到下一级队列的末尾。只有上层队列为空，才会调度下层。这样，短作业和交互式进程能在高优先级队列中很快完成，长作业逐渐下沉，用更大的时间片。不过，如果上层一直有新进程到来，下沉的长作业也可能饥饿。

| 算法              | 抢占                   | 饥饿 | 特点             |
| ----------------- | ---------------------- | ---- | ---------------- |
| 先来先服务 FCFS   | ×                      | ×    | 对长作业有利     |
| 短作业优先 SJF    | ×（有抢占式版本 SRTN） | √    | 平均周转周期最短 |
| 高响应比优先 HRRN | ×                      | ×    | 兼顾长短作业     |
| 时间片轮转 RR     | √                      | ×    | 分时系统、响应快 |
| 优先级调度        | 均可                   | √    | 区分紧急程度     |
| 多级反馈队列      | √                      | √    | 综合表现最好     |

### 信号量 Semaphore

互斥信号量初值一般为 1，同步信号量初值一般为 0，资源信号量初值就是资源数。

**PV 操作**：P（wait(S)）是申请一个资源，V（signal(S)）是释放一个资源。

```c
typedef struct {
        int value;
        struct process* L;
} semaphore;

void wait(semaphore S) {
        S.value--;
        if (S.value < 0) {
                block(S.L);
        }
}

void signal(semaphore S) {
        S.value++
        if (S.value <= 0) {
                wakeup(S.L);
        }
}
```
