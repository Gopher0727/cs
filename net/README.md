# 计算机网络

**数据通信、资源共享**

## 计算机网络概述

> 电路交换、报文交换、分组交换
>
> 时延：发送时延（数据长度 ÷ 发送速率）+ 传播时延（信道长度 ÷ 传播速率）+ 处理时延 + 排队时延
>
> 时延带宽积 = 传播时延 × 贷款

> 物理层：中继器、集线器
>
> 数据链路层：以太网交换机
>>
>> 封装成帧、透明传输、差错检测
>>
>> 点对点：PPP

## 可靠传输

**ARQ 确认+重传**

> 流水线传输 + 滑动窗口
>
> 停止等待协议 -> GBN（回退 N 帧）协议 -> SR（选择重传）协议

> MAC 介质访问控制
>
>> 信道划分、复用：FDM、TDM、STDM、WDM、码分多址 CDMA
>>
>> 随机访问：ALOHA、CSMA、CSMA/CD、CSMA/CA、令牌环

## 网络层（转发+路由选择）

软件定义网络 SDN 把传统路由器的控制和转发拆分开，由控制层面集中到 SDN 控制器，路由器只按 SDN 控制器下发的流表转发。

> 网络层（IP 地址）与数据链路层（MAC 地址）的传输过程怎么转换地址？-> ARP 协议
>
> 主机接入网络怎么获得 IP？-> DHCP 协议（基于 UDP，客户端端口 68，服务端端口 67）
>
> IP 出了问题怎么报告？-> ICMP 协议
>
> IP 地址不够，内网主机共享一个公网 IP？-> NAT
>
> 主机告诉本地路由加入了哪个组？-> IGMP

> 路由选择协议：
>
> AS 内部用 IGP（RIP（基于 UDP，端口 520） + OSPF（直接 IP））；外部用 BGP（基于 TCP，端口 179），不求路由最短
> 
> **RIP 路由表更新的时候，下一跳就是邻居的话，距离无条件替换**

## 运输层

UDP：DNS、DHCP、TFTP、SNMP、RIP

TCP：HTTP、FTP（文件传输）、SMTP（发送邮件）、POP3（接收邮件，下载到本地）、IMAP（接收邮件，始终保存在服务器）、Telnet、SSH、BGP
